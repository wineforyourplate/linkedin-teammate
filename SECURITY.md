# Security

Please do not open a public issue for a suspected security vulnerability. Use GitHub's private
vulnerability reporting on this repository instead.

Keep credentials, access tokens, connector accounts, member identifiers, environment-specific ids,
LinkedIn sessions and anyone's personal data out of this repository. The checked-in pod binds to
those after import.

When reporting, include the affected resource (table, function, agent, schedule or app), the trust
boundary crossed, and a minimal reproduction with no real credentials or personal data.
